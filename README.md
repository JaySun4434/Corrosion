## 数据与计算

- `data.js` — 标准计算参数、用户提供截图的 40 组 Annex A 原始节点、来源标签及特殊等级状态。
- `calc.js` — 分级、ISO 9223 剂量响应函数、ISO 9224 幂函数和 >20 年 Eq. (3)、Annex A 参考节点/线性插值、Annex B 指导速率、CSV 校验。
- `licensed-annex-a.js` — 可选的额外来源覆盖文件（默认空）；仅在取得相应权利时用于公开发布。
- `app.js` / `styles.css` — Swiss Style UI、响应式曲线、图例复选框、数据表、Tooltip、导出、复制。

### 时间模型

\(1\le t\le 20\): \(D(t)=r_{corr}t^b\)；\(20<t\le 50\): \(D(t)=r_{corr}[20^b+b20^{b-1}(t-20)]\)。B1/B2 均依 ISO 9224:2012 Table 2；Eq. (3) 为 20 年以后保守估算路径。工具的 50 年限值只是显示上限。

### 质量 / 厚度口径

累计厚度 `µm`，累计质量 `g/m²`，年速率分别为 `µm/a`、`g/(m²·a)`；不能将累计质量标为每年。铝只显示质量损失，不能用均匀质量损失替代局部点蚀深度。

1. **公式法 B1/B2**：使用所选首年厚度速率为计算基础，再按密度进行纯显示单位换算。切换结果单位不改变物理输入值。
2. **Annex A**：优先使用用户提供的 A.1 / A.2 截图录入的各单位原始节点进行插值，21 年后返回空值。绝不把厚度表乘密度冒充质量表。铝 C1、CX 保留非数值状态。
3. **Annex B**：使用现有经核查的区间上界作为两阶段指导速率；“快速估算法”是工具自身的比较假设，并非标准独立方法。铝没有可用的 Annex B 原表速率，故不计算。
4. **ISO 9223**：剂量响应返回 `µm/a`，对铝最终换算为 `g/(m²·a)` 并按其原始质量分级；SO₂ 浓度 `Pc (µg/m³)` 与沉降量 `Pd (mg/(m²·d))` 仅按 ISO 指定近似关系 `Pd = 0.8 Pc` 转换，超出回归环境范围给提示。

## 如获新版本授权，需要替换 A.1 / A.2

1. 打开 `annex_a_authorized_template.csv`。每行分别表示金属、等级、原始单位（`µm` / `g/m²`）以及 1、2、5、10、15、20 年的**原表值**。模板只包含字段；当前工具已内置由用户图片录入的参考节点。
2. 根据具有有效授权的正版标准录入数字；允许保留不适用的空行。请不要将自行计算值填入此模板充当 ISO 原始数据。
3. **静态网站更新**：取得版权许可后运行 `python build_authorized_data.py annex_a_filled.csv --rights-confirmed`，它会校验 6 节点、单位、行的唯一性与非递减性，生成 `licensed-annex-a.js`。再次运行 `python build.py` 生成最终文件。发布时务必确认许可明确覆盖公开数字工具和相关标准表格。

该模式优先采用独立单位的原表数据，不会错误地把 A.2 厚度节点换算成 A.1 的原值；对没有获授权原表的组合保持推算来源标签。
